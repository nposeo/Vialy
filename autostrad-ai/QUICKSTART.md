# 🚀 Быстрый старт AutostradAI

## Текущий статус

✅ Проект создан и запущен на http://localhost:5173

## Что реализовано

### ✅ Завершено
1. **Карта с react-leaflet** - интерактивная карта Украины
2. **Визуализация дорог** - цветовая кодировка по качеству:
   - 🟢 Зеленый - хорошее качество (М - международные)
   - 🟡 Желтый - среднее качество (Н - национальные)
   - 🔴 Красный - плохое качество (остальные)
3. **Smart Routing режимы**:
   - ⚡ Быстрый - все дороги равнозначны
   - 🛣️ Комфортный - плохие дороги полупрозрачные (визуально избегаются)
4. **UI с Tailwind CSS** - темный современный интерфейс
5. **Боковая панель** с:
   - Переключателем режимов
   - Информацией о выбранной дороге
   - Счетчиком токенов $AUTO
6. **Базовая интеграция Solana** - компоненты готовы

### ⚠️ В процессе установки
- Solana wallet adapter пакеты (установка идет в фоне)

## Как использовать прямо сейчас

1. Откройте http://localhost:5173 в браузере
2. Переключайте режимы "Быстрый" / "Комфортный"
3. Кликайте на дороги - появится popup с информацией
4. В режиме "Комфортный" плохие дороги становятся полупрозрачными
5. Выбранная дорога отображается в боковой панели
6. Кнопка "Подтвердить качество" начисляет +10 $AUTO токенов

## Следующие шаги

### Когда установятся Solana пакеты:
1. Перезапустите dev-сервер: `npm run dev`
2. Установите Phantom или Solflare кошелек
3. Подключите кошелек через кнопку в боковой панели
4. Подписывайте сообщения для подтверждения качества дорог

### Для полноценного Smart Routing:
Добавьте в Map.jsx построение маршрутов между двумя точками:
- Используйте `buildRoadGraph()` из `utils/routing.js`
- Вызовите `findShortestPath()` с учетом режима
- Отобразите маршрут на карте

## Технические детали

### Определение качества дорог
```javascript
// М - международные (хорошее)
if (name.startsWith('М ')) return 'good';

// Н - национальные (среднее)
if (name.startsWith('Н ')) return 'medium';

// Остальные (плохое)
return 'poor';
```

### Алгоритм маршрутизации
- Dijkstra с весами на основе качества
- В режиме "Комфортный": плохие дороги × 5 штраф
- Использует turf.js для расчета расстояний

### Solana интеграция
- Devnet для тестирования
- signMessage для подтверждения качества
- Формат сообщения: дорога + координаты + timestamp

### 3. Решенные проблемы

#### Проблема 1: Нехватка места на диске
**Решение:** Очистка npm cache, установка пакетов по одному

#### Проблема 2: Отсутствие viem
**Решение:** Установка viem как зависимости, но он вызывал конфликты с wallet-adapter-wallets

#### Проблема 3: Конфликт с wallet-adapter-wallets
**Решение:** Замена импорта на отдельные адаптеры (@solana/wallet-adapter-phantom, @solana/wallet-adapter-solflare)

#### Проблема 4: Tailwind CSS v4 несовместимость
**Решение:** Откат на Tailwind CSS v3

#### Проблема 5: Отсутствие leaflet
**Решение:** Установка leaflet и react-leaflet

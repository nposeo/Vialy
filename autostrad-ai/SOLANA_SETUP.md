# Установка Solana интеграции

## Проблема
При первоначальной установке возникла ошибка нехватки места на диске. Основное приложение работает, но Solana интеграция требует дополнительной установки.

## Решение

### Вариант 1: Освободить место и переустановить

```bash
# Очистите npm cache
npm cache clean --force

# Удалите node_modules
rm -rf node_modules

# Установите все зависимости заново
npm install
```

### Вариант 2: Установить только Solana пакеты

```bash
# Установите минимальный набор для Solana
npm install @solana/web3.js @solana/wallet-adapter-base @solana/wallet-adapter-react @solana/wallet-adapter-react-ui @solana/wallet-adapter-wallets
```

### Вариант 3: Работать без Solana (текущий режим)

Приложение полностью функционально без Solana:
- ✅ Карта работает
- ✅ Визуализация дорог работает
- ✅ Переключение режимов работает
- ✅ Подтверждение качества работает (без подписи кошельком)
- ✅ Начисление токенов работает (локально)

## Проверка установки

После установки Solana пакетов проверьте:

```bash
# Проверьте наличие пакетов
ls node_modules/@solana

# Перезапустите dev-сервер
npm run dev
```

## Если Solana установлен

1. Установите Phantom или Solflare кошелек в браузере
2. Откройте http://localhost:5173
3. Нажмите "Подключить кошелек"
4. Выберите дорогу на карте
5. Нажмите "Подтвердить качество"
6. Подпишите сообщение в кошельке
7. Получите +10 $AUTO токенов

## Текущий функционал без Solana

Приложение работает в упрощенном режиме:
- Кнопка "Подключить кошелек" показывает подсказку
- "Подтвердить качество" работает без подписи
- Токены начисляются локально (не в блокчейне)

Это позволяет протестировать весь UI и логику приложения.

## Альтернатива: Использовать AppSimple.jsx

Создан упрощенный компонент без зависимостей от Solana:

```bash
# В src/main.jsx замените
import App from './App.jsx'
# на
import App from './AppSimple.jsx'
```

Это полностью рабочая версия без Solana интеграции.

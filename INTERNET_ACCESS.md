# 🌐 AutostradAI - Доступ из интернета

## ✅ Приложение готово к публикации!

Файлы размещены в: `D:\server\OpenServer\domains\AutostradAI\www\`

## 🚀 Быстрый способ (через ngrok) - РЕКОМЕНДУЕТСЯ

### Шаг 1: Скачать ngrok
1. Перейдите на https://ngrok.com/download
2. Скачайте версию для Windows
3. Распакуйте в удобную папку

### Шаг 2: Зарегистрироваться (бесплатно)
1. Зарегистрируйтесь на https://dashboard.ngrok.com/signup
2. Скопируйте ваш authtoken со страницы https://dashboard.ngrok.com/get-started/your-authtoken

### Шаг 3: Настроить ngrok
Откройте командную строку и выполните:
```bash
cd путь\к\ngrok
ngrok config add-authtoken ваш-токен
```

### Шаг 4: Запустить туннель
```bash
ngrok http 80
```

### Шаг 5: Получить публичный URL
После запуска вы увидите:
```
Forwarding  https://xxxx-xx-xx-xx-xx.ngrok-free.app -> http://localhost:80
```

**Это ваш публичный URL!** Отправьте его кому угодно - приложение будет доступно из любой точки мира.

## 📱 Пример использования

1. Запустите OpenServer (Apache должен быть запущен)
2. Запустите ngrok: `ngrok http 80`
3. Скопируйте URL из строки "Forwarding"
4. Откройте этот URL в браузере
5. Поделитесь URL с другими

## ⚙️ Альтернативные способы

### Вариант 2: Локальная сеть

Если нужен доступ только в локальной сети:

1. Узнайте ваш IP:
```bash
ipconfig
```
Найдите "IPv4 Address" (например, 192.168.1.100)

2. Откройте в браузере:
```
http://192.168.1.100/
```

### Вариант 3: Внешний IP (постоянный)

Для постоянного доступа через интернет:

1. Узнайте внешний IP: https://whatismyipaddress.com/
2. Настройте Port Forwarding на роутере:
   - Зайдите в настройки роутера (обычно 192.168.1.1)
   - Найдите раздел "Port Forwarding" или "Virtual Server"
   - Добавьте правило:
     - External Port: 80
     - Internal IP: ваш-локальный-ip
     - Internal Port: 80
     - Protocol: TCP
3. Откройте порт в Windows Firewall
4. Доступ по адресу: `http://ваш-внешний-ip/`

⚠️ **Внимание:** Этот способ может быть небезопасен без HTTPS!

## 🎯 Рекомендация для продакшена

Для постоянного размещения лучше использовать облачный хостинг:

### Vercel (бесплатно, 5 минут)
```bash
# Установить Vercel CLI
npm install -g vercel

# Перейти в папку проекта
cd autostrad-ai

# Задеплоить
vercel

# Следовать инструкциям
```

Получите URL типа: `https://autostrad-ai.vercel.app`

### Netlify (бесплатно, drag & drop)
1. Перейдите на https://app.netlify.com/drop
2. Перетащите папку `dist/` в окно браузера
3. Получите URL типа: `https://random-name.netlify.app`

## 🔧 Проверка работы

1. Убедитесь, что OpenServer запущен
2. Откройте http://localhost/ в браузере
3. Должна загрузиться карта с дорогами Украины
4. Проверьте работу переключателя режимов
5. Попробуйте кликнуть на дорогу

## 💡 Советы

- **ngrok** - идеально для демонстрации и тестирования
- **Vercel/Netlify** - лучше для постоянного размещения
- **Свой сервер** - требует настройки, но дает полный контроль

## 🆘 Если что-то не работает

1. Проверьте, что Apache запущен в OpenServer
2. Проверьте, что порт 80 не занят
3. Откройте http://localhost/ - должно работать локально
4. Проверьте логи Apache в OpenServer
